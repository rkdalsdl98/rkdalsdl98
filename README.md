안녕하세요, 사용자 중심 설계로 신뢰할 수 있는 서비스를 만드는 백엔드 개발자 한강민입니다.
주로 TypeScript와 NestJS로 개발하며, 실제 문제를 안정적이고 구조가 분명한 시스템으로 풀어내는 일을 좋아합니다.

무엇을 만드는지만큼이나 어떻게 만드는지를 중요하게 생각합니다. 데이터 모델링과 API 설계부터 문서화, 품질을 일관되게 유지하는 도구까지 고민하며, 사용자와 팀 모두에게 실질적인 가치를 주는 개발자로 꾸준히 성장하고 있습니다.
